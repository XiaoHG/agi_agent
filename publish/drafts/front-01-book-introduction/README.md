# 书籍简介

本书是一部围绕真实项目展开的专业 Agent 学习书籍，目标不是展示若干零散技巧，而是帮助读者建立完整的 Agent 工程视角。

书中会从最小可运行原型出发，逐步展开一个 Agent 系统在工程化过程中必须补齐的关键能力：执行闭环、状态与工作流、知识增强、工具边界、多智能体协作、模型决策、结构化运行时、可观测性、恢复机制与系统治理。所有核心章节都将尽量回到真实项目中的代码入口、版本演进和验证证据，而不是停留在抽象概念层面。

这本书并不试图替代框架文档，也不追求用最短篇幅覆盖最多名词。它更关心的是另一件事：一个真正可持续演进的 Agent 项目，应当如何建立边界、如何组织能力、如何验证系统，并最终从可运行原型走向工业级工程系统。

如果你希望系统学习 Agent，而不仅仅是拼装一个能跑的 demo，这本书将为你提供一条更稳定、更可迁移的学习路径。
