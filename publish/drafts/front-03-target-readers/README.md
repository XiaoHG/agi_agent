# 本书面向谁

这本书主要面向以下三类读者。

第一类，是已经具备 Python 基础，希望系统进入 Agent 工程领域的开发者。你也许已经接触过大模型调用、提示词、简单工具接入，但尚未形成完整的 Agent 结构认知。本书会帮助你从执行闭环开始，逐步理解状态、知识、协议、协作和运行时治理这些能力为什么必须进入系统边界。

第二类，是已经做过一些 LLM 应用或原型，但发现系统一旦变复杂就很难继续维护的工程师。对这类读者来说，本书最有价值的部分，不是单个技巧，而是对“如何建立边界、如何组织层次、如何验证系统”的持续解释。

第三类，是希望结合真实项目理解 RAG、MCP、Skills、Subagent、LangGraph 等能力如何进入统一主链路的读者。本书不会把这些主题拆成互相孤立的工具清单，而会强调它们在同一个 Agent 系统中分别承担什么职责。

如果你的目标只是快速拼装一个演示性质的应用，那么这本书可能会显得过于强调结构和取舍。但如果你希望理解一个 Agent 为什么能够持续演进、为什么在工程上站得住，这本书更适合你。
