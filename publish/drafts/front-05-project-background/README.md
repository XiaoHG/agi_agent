# 项目背景与学习路线

本书依托的不是一个一次性示例仓库，而是一个持续演进的 Agent 学习项目。这个项目从最小 CLI Agent 起步，随后逐步引入状态与工作流、本地 RAG、本地 MCP、Skills 与 Subagent、真实 LLM 接入、tool calling、tool loop、LangGraph 编排，以及更靠近工业化阶段的可观测性、恢复、权限和运行治理能力。

这条演进路线之所以适合作为书稿基础，是因为它不是无序叠加功能，而是围绕一组不断暴露出来的工程问题向前推进。每一个新增能力，背后都对应着一个前一阶段无法继续支撑的问题：单步决策不够用，于是状态和工作流出现；静态知识不足，于是 RAG 进入主链路；单一工具方式难以扩展，于是协议和能力分层逐渐成形；系统开始变复杂，于是运行时、恢复和治理变成必需项。

因此，本书不会简单按版本号讲故事，而会把这些版本材料重新归并成更符合学习规律的章节主线。版本是证据来源，不是目录本身；学习路线才是书稿真正的主线。

你可以把整本书理解为一条逐步加深的路径：

1. 先理解 Agent 是什么，以及它与普通 LLM 应用的根本区别。
2. 再理解一个工业级 Agent 最基础的结构边界。
3. 然后进入最小闭环、状态与工作流、知识增强和工具协议。
4. 再继续进入协作、模型决策、图式运行时。
5. 最后回到工业级系统必须面对的可观测性、恢复和治理问题。

这条路径与项目演进互相支撑：项目提供真实实现，书稿提供稳定结构，读者则通过两者之间的对应关系建立自己的工程认知。
