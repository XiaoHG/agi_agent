# 作者序

这本书并不是先有书名，再去寻找素材；它的起点，是一个长期演进的本地 Agent 工程项目。

最初，这个项目的目标非常直接：先做出一个最小 CLI Agent，让系统至少具备输入、路由、工具调用和输出这条最基本的执行闭环。但当最小闭环建立起来之后，问题并没有结束，反而变得更加具体。系统如何支撑多步任务？如何把知识检索纳入主链路？如何让工具和协议边界更加稳定？如何把多智能体协作从概念变成可控结构？如何在系统复杂之后，仍然具备可观测性、恢复能力与运行治理？

随着这些问题不断出现，项目逐步从一个学习型原型演化成一条较完整的 Agent 工程主线。与此同时，我也越来越明确地意识到，仅仅保留代码、版本说明和练习文档，并不足以支撑系统学习。项目材料能够证明做过什么，却不一定能让后来者理解为什么要这样做、为什么要按这样的顺序推进，以及哪些工程判断才是真正值得保留下来的部分。

因此，这本书真正要整理的，不只是项目功能本身，而是一个 Agent 系统如何一步一步长成今天这个样子的过程与方法。书中的技术内容并不脱离项目，但它也不会等同于项目文档。项目负责提供真实证据，书稿负责把这些证据转化成可学习、可复盘、可迁移的知识结构。

如果这本书能够帮助读者少走一些“先堆功能、后补结构”的弯路，真正理解 Agent 为什么必须作为系统工程来构建，那么它就达到了自己的目的。
