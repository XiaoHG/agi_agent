# drafts/

这里存放书稿主文稿，按“前置部分 / 正文部分 / 附录部分”的正式技术书结构组织。

## 当前组织方式

### 前置部分

- `drafts/front-01-book-introduction/README.md`
- `drafts/front-02-author-preface/README.md`
- `drafts/front-03-target-readers/README.md`
- `drafts/front-04-how-to-use/README.md`
- `drafts/front-05-project-background/README.md`

### 正文部分

- `drafts/prologue/README.md`
- `drafts/ch01/README.md`
- `drafts/ch02/README.md`
- `drafts/ch03/README.md`
- `drafts/ch04/README.md`

## 维护规则

- 每个目录下的 `README.md` 作为当前主稿。
- 前置部分不直接承担核心技术章节的展开。
- 正文章节按知识结构递进组织，不按项目版本顺序直接排列。
- 如果后续需要分节扩写，可在对应目录内继续增加子文件。
- 草稿更新后，要同步更新 `manuscript-status.md`、`current-book-summary.md`、`research/` 和 `revisions/`。
