# 术语表

## AgentRun

一次 Agent 执行的结构化记录，包含输入、路由、步骤、工具结果、错误和最终回答。

## route_intent()

把自然语言输入映射成可执行路由的函数。

## ToolRoute

描述用户请求应该如何处理的路由结果。

## WorkspaceAgent

项目中的主 Agent 执行器，负责调度路由、工具、工作流和最终输出。

## AgentState

工作流阶段使用的可变状态对象，用来保存步骤、工具结果和中间输出。

## WorkflowPlan

工作流计划对象，描述多步任务应该如何顺序执行。

## trace

一次执行的可观察记录，用来调试、回归和复盘 Agent 行为。
