# docs/

放学习笔记、设计文档、架构图和复盘。

当前目录约定：

- `vNN_*.md`：按版本排序的练习文档。
- `plans/`：学习总纲、阶段计划、任务计划。
- `reviews/`：阶段复盘、专题总结、项目回顾。
- `references/`：流程图、架构图、辅助说明。
- `snapshots/`：阶段工作快照和恢复材料。
- `templates/`：复盘模板等可复用文档。

同步规则：

- `versions/`、`docs/vNN_*.md`、`docs/current-learning-state.md` 必须描述同一版本进度。
- 每次提交新版本后，要同时更新版本说明、练习答案和学习状态。
- 如果三者信息不一致，以最新提交状态和总纲为准。

适合放：

- 每周复盘
- 架构设计说明
- 失败案例分析
- 技术选型记录
- 源码阅读笔记

建议优先按版本号或主题归档，不要继续把不同用途的文档混放在顶层。
