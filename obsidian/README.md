# Obsidian 项目说明

`obsidian/` 用于承接本项目的学习导航、架构地图、版本理解、问题决策、复盘记录和路线规划。

这里不是 `docs/` 的替代品，而是项目的“认知层”和“项目驾驶舱”。

分工原则：

- `README.md` / `docs/` / `versions/`：正式工程文档
- `obsidian/`：可学习、可链接、可复盘、可导航的项目知识网络

建议优先阅读：

- `01-首页/项目导航.md`
- `01-首页/当前学习驾驶舱.md`
- `07-架构链路/工业Agent主链路.md`
- `03-版本管理/版本演进总图.md`
- `06-代码追踪/模块总览.md`

目录说明：

- `01-首页/`：总入口、当前驾驶舱和全项目导航
- `02-项目全景/`：项目目标、当前阶段、全景总图、学习路径
- `03-版本管理/`：版本总台账、阶段分组、关键版本页、`versions/` 镜像
- `04-文档管理/`：正式文档入口、docs 索引、练习索引、项目文档镜像
- `05-出版资料/`：书稿、研究材料、出版流程与 `publish/` 镜像
- `06-代码追踪/`：模块地图、代码入口总览、文档与代码双向映射
- `07-架构链路/`：主链路、专题链路、Mermaid 图
- `08-问题与决策/`：关键取舍、缺口与设计判断
- `09-学习复盘/`：阶段学习记录
- `10-计划与路线/`：路线图与后续版本计划
- `11-术语与概念/`：术语卡片
- `12-模板/`：后续新增笔记时复用的模板
- `13-附件/`：导图图片、Canvas 资源等
