# 运行证据与恢复链路

## 结论

当前项目的工程价值，很大一部分不在“能不能答题”，而在“答题过程能不能留下证据、能不能回放、能不能恢复、能不能比较不同版本行为”。

## 运行证据数据流

```mermaid
flowchart LR
    Run[AgentRun / graph_state]
    Trace[to_trace_dict / format_trace]
    Events[build_runtime_events]
    Memory[AgentMemoryStore]
    Checkpoint[build_run_checkpoint]
    Store[RunCheckpointStore\nlogs/agent-runs/*.json]
    Replay[format_replay_report]
    Resume[build_checkpoint_resume_plan\nresume_checkpoint]
    Diff[format_replay_diff_report]

    Run --> Trace
    Run --> Events
    Trace --> Memory
    Trace --> Checkpoint
    Events --> Checkpoint
    Memory --> Checkpoint
    Checkpoint --> Store
    Store --> Replay
    Store --> Resume
    Store --> Diff
```

## 恢复与比较时序

```mermaid
sequenceDiagram
    participant CLI as cli/main.py
    participant Agent as WorkspaceAgent
    participant Store as RunCheckpointStore
    participant Replay as agent/replay.py

    CLI->>Agent: --resume-run / --replay-run / --compare-runs
    Agent->>Store: load_run(run_id) / load_latest()
    Store-->>Agent: checkpoint record

    alt replay
        Agent->>Replay: format_replay_report(record)
        Replay-->>Agent: replay text
    else resume
        Agent->>Replay: build_checkpoint_resume_plan(record)
        Agent->>Agent: run(user_input, route_override, branch session/task)
        Agent->>Store: save(new branch checkpoint)
    else compare
        Agent->>Replay: format_replay_diff_report(old, new)
        Replay-->>Agent: diff text
    end
```

## 状态与产物

- 运行态对象：
  - `AgentRun`
  - `AgentStep`
  - `RuntimeEvent`
  - `MemorySnapshot`
- 持久化产物：
  - `latest.json`
  - `<run_id>.json`
- 回放类能力：
  - replay
  - compare
  - resume
