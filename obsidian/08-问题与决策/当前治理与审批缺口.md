# 当前治理与审批缺口

## 结论

项目已经有 policy、governance、release gate 等基础，但还没有形成正式的人类审批和运行治理闭环。

## 已有基础

- MCP governance
- Skills governance
- release gate
- recovery plan

## 未有能力

- approval request / decision record
- 高风险操作的显式暂停
- 多 Agent 关键切换时的人工确认
- 面向长期任务的治理状态

## 为什么暂时没先做

因为审批需要依赖：

- 更真实的 task runtime
- 可以挂起和恢复的执行状态
- 清晰的风险分类入口
