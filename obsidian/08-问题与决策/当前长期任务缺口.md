# 当前长期任务缺口

## 结论

当前项目已经有 checkpoint / replay / resume，但还没有真正把“任务”作为长期运行对象完整管理起来。

## 现有基础

- checkpoint persistence
- replay
- replay diff
- guided resume
- memory
- subagent runtime session

## 缺少的能力

- pause / resume / expire / abandon
- milestone record
- task health / watchdog
- 跨天任务续跑
- 人工确认节点

## 依赖关系

长期任务能力依赖：

- 多 Agent async runtime
- 状态机更完整
- 审批和人工接管边界
