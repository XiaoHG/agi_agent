# 版本演进总图

## 结论

项目版本演进不是线性加功能，而是沿着“运行时、能力层、证据层、治理层、多 Agent 主线”逐步收敛。

## 阶段划分

### 第一阶段：基础 Agent

- v01-v07
- 最小 CLI、状态、RAG、MCP、Skills/Subagent、工程化基础

### 第二阶段：真实 LLM 与 LangGraph

- v08-v18
- 真实 LLM、tool calling、tool loop、LangGraph 主干接入

### 第三阶段：证据与恢复

- v19-v28
- skill execution、trace、runtime events、checkpoint、replay、planner

### 第四阶段：专业能力与治理

- v29-v49
- professional RAG、registry、governance、release gate、resume、memory

### 第五阶段：多 Agent 主线

- [[v50-委派协议硬化-理解版]]
- [[v51-多Agent运行时基础-理解版]]
- [[v52-异步委派队列计划]]

## 当前关键版本

- `v50`：从 plan 进入可执行委派协议
- `v51`：从协议进入 runtime foundation
- `v52`：从 runtime foundation 进入 async queue
