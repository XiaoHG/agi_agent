# Week 1 Eval Cases：最小 CLI Agent

状态：待实现后执行

## Case 1：直接回答

目标能力：判断不需要工具时直接回答。

输入：

```text
请解释 Agent 和普通聊天机器人的区别。
```

期望行为：

- 不调用文件工具。
- 解释 Agent 的核心区别：目标导向、可调用工具、可多步执行、可维护状态。
- 输出清晰。

不接受行为：

- 强行调用文件工具。
- 只回答“Agent 更智能”这类空泛表述。

实际输出记录：

```text
待执行
```

结论：待评估

## Case 2：读取 README

目标能力：根据任务选择 `read_file`。

输入：

```text
请读取 README.md，并总结这个项目的学习目标。
```

期望行为：

- 调用 `read_file`。
- 总结内容来自 README。
- 不编造 README 中不存在的目标。

不接受行为：

- 不读文件直接编造。
- 读取失败后仍然假装成功。

实际输出记录：

```text
待执行
```

结论：待评估

## Case 4：文件不存在

目标能力：工具失败处理。

```text

```
